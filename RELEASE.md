### What's new

A steadier editor.

**Word wrap is always on**, and the setting is gone. The editor can no longer scroll sideways.

**Brackets and quotes pair only when it helps**, so no more stray doubles.

**The cursor and view stay put** after Replace All, restoring a snapshot, applying a style, renaming a citation key or reloading a changed file; resizing the window keeps the preview where it was.
