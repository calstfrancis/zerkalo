### What's new

One place to get anything back.

**Recover… (☰ → Recover…).** A single window that asks "What do you want back?" and tells you, in plain words, how safe your work is. It gathers earlier versions saved on this computer and backed up online into one timeline, shows what each would bring back with the changes highlighted, and lets you **search every earlier version** for words you remember.

**Bringing something back never overwrites.** *Bring back as a copy* saves the earlier text beside the original as a new file. *Replace what's here…* is a separate, confirmed choice that keeps the current text first, and Ctrl+Z undoes it.

**Saved copies without the command line.** The copies kept before "Replace with GitHub's copy" are listed by date, and any file can be brought back beside its current one. Deleted documents and Get Latest from GitHub are one click away too.

The crash-recovery question now says how many words restoring would bring back or take out, and "Git Change History…" is now "Online Change History…".
